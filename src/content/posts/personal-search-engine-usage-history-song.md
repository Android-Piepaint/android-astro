# Intro

全球資訊網(史上)第一，是 Archie 和 Gopher,</br>
1991 年創立，13年統治 </br>
(選單)結構限制，最終被趕下臺 </br>
世上第一搜尋引擎，就這樣退場 </br>
</br>

# Part 1

華文搜尋第一，(我們)臺灣蕃薯藤 </br>
1995 年成立，服務(使用者)至今 </br>
即使政治色彩濃厚，「第一」不可否 </br>
感謝 Yam 大統領，我們的大統領* </br>
</br>

> _*大統領：總統。因爲搜尋引擎在如今全球資訊網中有重要地位，借用此名詞。_</br>
</br>

# Part 2

專有軟體出發，美國 Google 會社 </br>
1998 年以來，統治網路至今 </br>
蒐集隱私好手，使用者苦不堪言 </br>
感謝 Google 大統領，我們的大統領 </br>
</br>

# Part 3

南韓市佔最高，韓國 Naver 檢索 </br>
1999 年成立，(僅僅)使用6個月 </br>
新聞電郵(電子)地圖，服務獨佔鰲頭 </br>
(無用)資訊氾濫，廣告漫天，真讓我爲難 </br>
</br>

# Part 4

專有軟體再臨，美國 Yahoo! 搜尋 </br>
1994 年成立，(至今)32年統治 </br>
向政府出賣個資，廣告無處不在 </br>
並不感謝 Yahoo ，卻是我的網路教師 </br>
</br>

# Part 5

普通愛好者趣味*(自架)，FrogFind 檢索 </br>
2023 年成立，專爲老舊硬體 </br>
雖然設計簡單，卻足夠瀏覽網路 </br>
感謝 FrogFind 大統領，我們的大統領 </br>
</br>

> _*趣味：興味，興趣愛好_ </br>
</br>

# Part 6

間諜軟體出發，中國百度檢索 </br>
虛假信息干擾，網路搜尋實名制 </br>
以隱私換方便，Google 自愧不如 </br>
不曾使用百度搜尋，也不會感激 </br>
</br>

# Part 7 

隱私保護出發，美國鴨走走(DuckDuckGo)搜尋，</br>
Onion (網址)匿名化搜尋，是重大變革 </br>
從不記錄/蒐集隱私，一切功能從簡 </br>
感謝 DuckDuckGo 大統領，我們的大統領 </br>
</br>

# Part 8  

開源自架(軟體)出發，SearXNG (元)搜尋 </br>
集合搜尋，統一檢索，高度客製化 </br>
只需支援 Docker 容器就可以實作 </br>
**隱私牢牢掌控，做自己的大統領** </br>
</br>

# Part 9

實用從簡出發，荷蘭 Startpage 檢索 </br>
1998 年成立，28年歷史 </br>
沒有總結，AI 服務，只有質朴耐用 </br>
感謝 Startpage 大統領，不再依賴過度 </br>
</br>

# Part 10

最早元搜尋引擎是 Dogpile, </br>
1996 年建立，30年歷史 </br>
介面設計不禁讓人回想到從前, </br>
無憂無慮的時代，如今一去不返 </br>
</br>

# Part 11

下面要介紹的間諜軟體是 Bing 搜尋,</br>
介面華麗，Copilot 助理，盜走我個資 </br>
儘管 AI 助理曾經幫助我事務, </br>
可牠是專有軟體，內建追蹤器 </br>
</br>

# Part 12

革命軟體出發，Claude AI 檢索 </br>
功能多樣，程式開發是拿手絕活 </br>
在大統領幫助下我開始 Linux 移植,</br>
雖然過程艱難，但我依舊熱愛 </br>

# Chorus

回顧過去使用搜尋引擎的歷程，</br>
捍衛個人隱私已是我的必選項 </br>
我不是犯罪分子也不是異見人士，</br>
只想守護個資，捍衛數位主權 </br>
</br>

# Ending

縱使守護個資之路再遠再艱難，</br>
**(依然)捍衛個人隱私，做自己的大統領** </br>
</br>
